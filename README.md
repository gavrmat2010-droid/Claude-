# Солнечная система — прошлое и будущее

Интерактивная модель Солнечной системы в браузере: все планеты на анимированных орбитах, карточка с фактами по клику и шкала времени от рождения системы (4,6 млрд лет назад) до её конца (10 млрд лет вперёд). При перемотке Солнце раздувается в красного гиганта, поглощает внутренние планеты, сбрасывает оболочку и становится белым карликом, а у каждой планеты меняется внешний вид и описание того, что с ней происходит.

## Запуск

```bash
pnpm install
pnpm dev        # http://localhost:5173
pnpm build      # production-сборка в dist/
pnpm preview    # посмотреть сборку
pnpm typecheck
```

## Как устроено

- `src/data/bodies.ts` — характеристики Солнца и планет и их «хроника»: список эпох с текстом и визуальным состоянием (цвета, кольца, расплавлена/замёрзла/поглощена).
- `src/lib/sun.ts` — модель эволюции Солнца (радиус, светимость, температура, масса) как функция времени: протозвезда → главная последовательность → субгигант → красный гигант → горение гелия → AGB → планетарная туманность → белый карлик.
- `src/lib/state.ts` — состояние тела в момент времени: активная эпоха, расширение орбиты из-за потери массы Солнцем, оценка температуры, факт поглощения.
- `src/lib/time.ts` — кусочно-линейная шкала ползунка, чтобы насыщенным событиями эпохам доставалось больше места.
- `src/components/Scene.tsx` — рендер на Canvas 2D: звёздное небо, орбиты в логарифмическом масштабе, освещение планет Солнцем, кольца, протопланетный диск, туманность.
- `src/components/InfoPanel.tsx`, `TimeBar.tsx`, `BodyStrip.tsx` — карточка тела, шкала времени с автопрокруткой, выбор тела.

Стек: Vite, React 19, TypeScript, Tailwind CSS 4. Масштабы орбит и размеров условные, сроки событий — оценки по современным астрофизическим моделям.
